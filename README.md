# MediCare Connect Server

Welcome to the backend server for MediCare Connect, a modern healthcare platform.

## Application Endpoints
- **Backend Server**: [http://localhost:5000](http://localhost:5000)
- **Frontend Client**: [http://localhost:3000](http://localhost:3000)

## Admin Credentials
For testing and administrative actions, use the following credentials:
- **Admin Email**: `admin@medicare.com`
- **Admin Password**: `AdminPassword123!`

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env` environment variables.
3. Start the development server:
   ```bash
   node index.js
   ```
